# React Hello World

Vite + React + TypeScript app that displays **Hello World**.

## Live

- Cloudflare Pages: https://react-hello-world-e0d.pages.dev/
- Repo: https://github.com/youngclaude/react-hello-world

## Local

```bash
npm install
npm run dev
npm run build
```

## Deploy

Connected to Cloudflare Pages. Pushes to `main` run `npm run build` and publish `dist/`.
